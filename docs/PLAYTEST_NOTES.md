성공 n개를 쌓은 **뒤 다음 동전**의 기준이다. 속도는 실행 상태에서 읽었고 시간은 규칙으로 계산했다. 시간 폭은 중앙 목표를 지나는 한 번의 통과에서 양쪽 허용 범위를 합한 값이다.

| 성공 개수 | 속도(논리 px/s) | 편도 이동 | Perfect 가능 시간 폭 | 전체 성공 시간 폭 |
| --------- | --------------- | --------- | -------------------- | ----------------- |
| 5         | 425             | 1.092초   | 78.1ms               | 234.4ms           |
| 10        | 500             | 0.928초   | 66.4ms               | 199.2ms           |
| 20        | 650             | 0.714초   | 51.1ms               | 153.2ms           |

20개 구간의 Perfect 폭은 60Hz 기준 약 3.1프레임, 중앙 시점 기준 앞뒤 약 25.5ms다. 5개 때보다 폭이 약 35% 줄어 타이밍 오차에 민감해질 수 있다는 추론이며, 실제 플레이가 너무 어렵다는 사용자 판단은 아니다.

배포 화면에서 HUD 판 누락도 관측했다. CSS 배경 이미지 디코딩 검사로 실패를 재현하고 URL 기준을 수정했다. 배포 캡처도 다시 확인했다.
