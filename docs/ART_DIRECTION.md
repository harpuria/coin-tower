# Coin Tower 웹 아트 방향

## 동전 스킨

- [결정] 기존 `coin.png`와 같은 구도·크기의 은화·루비·에메랄드 스킨 3종을 제작한다. 기본 금화는 보존한다. 스킨으로 동전의 판정·크기·속도를 바꾸지 않는다.
- 제작 시안: 원형 테두리·왕관·옆면 홈·두께·광원을 유지하고, 은화는 차가운 은색 금속, 루비는 진홍색 보석, 에메랄드는 녹색 보석 재질로 구분했다. 보석 면은 기존 표면 안에 두며 외곽에 장식·입자·돌출 보석을 붙이지 않는다.
- 세 파일 모두 원본과 같은 1599×984 RGBA다. 원본과 동일한 표시 frame을 사용하며, 생성 결과의 수 픽셀 실루엣 차이·용량·출처·프롬프트·장면 관측은 [제작 기록](art/coin-skins.md)을 따른다. 구매·장착 기능에 연결했으며 목록은 HTML 미리보기, 메뉴와 플레이는 Phaser의 동일한 art frame을 사용한다. 구매·저장 규칙은 [경제 설계](design/economy.md)를 따른다.

## 메인 화면

- [결정] BEST ON THIS BROWSER 제목과 시작 문구 아래의 조작 설명은 표시하지 않는다. 두 개인 최고와 별조각은 아이콘+숫자로 유지한다.
- [결정] 파란 PLAY 버튼 판을 제거하고 배경 위에 TAP TO PLAY 이미지 글자를 표시한다. 문구 선택과 화면의 마우스·주 터치·Space로 시작할 수 있으며 시작 입력은 첫 낙하를 겸하지 않는다.
- 제작한 시작 글자는 기존 TOWER의 밝은 흰 얼굴·파란 베벨·짙은 외곽선을 따른다. 장식 별·왕관·판을 추가하지 않으며 원본 로고·Perfect는 보존한다. 스타일 세부는 구현한 시안이며 사용자 체감은 후속 피드백에서 확인한다.
- 이미지 영역에는 키보드 포커스와 접근성 이름을 보존한다. 로딩·오류 중에는 시작하지 않고 SOUND/FULLSCREEN 같은 실제 설정 조작은 시작 입력으로 처리하지 않는다.
- 파일·전체 프롬프트·출처·표시 크기·관측 한계는 [TAP TO PLAY 제작 기록](art/tap-to-play.md)을 따른다.

## 기록·별조각 아이콘

- [결정] BEST COIN, BEST COMBO, STAR SHARDS용 아이콘 이미지를 먼저 제작한다. 후속 요청에 따라 메뉴·결과·인게임에도 적용한다.
- 제작안: 최고 적층은 왕관이 있는 금화 탑, 최고 콤보는 이어지는 금빛 네 갈래 섬광, 별조각은 청록색 다섯 갈래 별 결정으로 구분한다. 글자는 이미지에 넣지 않았다.
- 기존 `coin.png`의 광택·따뜻한 금색 측면과 `perfect.png`의 밝은 하이라이트·둥근 베벨·외곽선을 참조했다. 파란 패널과 청록색 패널 위의 축소 미리보기로 비교했다.
- 파일: `public/assets/coin-tower/icons/best-coins.png`, `best-combo.png`, `star-shards.png`. 투명 PNG이며 생성 원본을 그대로 보존했다. 실제 해상도·프롬프트·해시·관측 한계는 [제작 기록](art/ui-icons.md), 이용 조건은 [자산 출처](ASSET_SOURCES.md)에 있다.
- 메뉴는 아이콘+개인 최고 두 칸과 별조각 잔액, 결과는 아이콘 행+THIS RUN/BEST와 별조각 EARNED/TOTAL, 인게임은 오른쪽 두 줄의 최고 기록·보유량과 COINS를 사용한다. 항목 이름은 접근성 텍스트와 마우스 설명에 유지한다.
- 원본 픽셀은 보존하고 CSS 표시 영역으로 투명 여백을 제외해 실루엣 크기를 맞췄다. 숫자는 자릿수에 따라 줄이며 로고·Perfect/X·일시정지와 겹치지 않도록 배치했다. 현재 화면 관측과 한계는 [검증 기록](VALIDATION.md)을 따른다.

### 기록·재화의 화면 표시 원칙

- [결정] 기록과 별조각은 테두리·채움·버튼형 판 없이 **아이콘+숫자**를 배경 위에 직접 표시한다. 메뉴·결과·인게임 모두 적용하며 현재 COINS도 같은 표시 원칙을 따른다. 사용자가 버튼 안의 아이콘이 어색하다는 피드백 뒤 이 방향을 채택했다.
- [결정] 메뉴의 두 최고 기록과 별조각 잔액, 결과의 THIS RUN/BEST 비교 열·항목별 NEW BEST·별조각 EARNED/TOTAL, 인게임의 개인 최고와 현재 점수 구분을 유지한다. 항목 이름은 접근성 텍스트·마우스 설명으로 보존한다.
- [결정] 숫자는 금색 기록·밝은 청록색 별조각으로 구분하고 짙은 외곽선과 짧은 그림자로 밝고 어두운 배경에서 읽히게 한다. 아이콘을 조금 키우고 숫자와 가깝게 정렬한다. 긴 값은 가용 폭에 맞춰 축소한다.
- [결정] TRY AGAIN·MENU·일시정지 등 실제 조작 요소는 버튼으로 유지한다. 시작은 아래 메인 화면의 이미지 문구를 사용한다. 기록·재화 표시에는 호버·눌림 연출이나 클릭 동작을 부여하지 않는다.
- [가설] 박스를 없애면 정보가 버튼처럼 보이는 혼동과 화면의 답답함이 줄어든다. 사용자 피드백은 기존 버튼형 배치의 어색함을 뒷받침하지만, 변경 후의 가독성과 편안함은 PC 플레이에서 다시 확인한다.
- 확인 조건: 아침·점심·저녁·밤에서 숫자·아이콘·열 제목이 배경과 구분되고 서로 겹치지 않아야 한다. 로고·Perfect/X·낙하 동전·조작 영역을 보존하고 NEW BEST 두 개와 여러 자리 숫자도 확인한다.

## 시간대 배경

- [결정] 기존 아침 느낌의 배경을 보존하고, 적층 높이에 따라 시간의 흐름을 표현할 배경 변형을 준비한다. 2026-10-09 사용자 요청을 따른다.
- 제작한 변형: 점심의 맑은 파랑·중성 흰빛, 노을 진 저녁의 살구·주황·라벤더, 밤의 남색·푸른 달빛 느낌. 유적·폭포·배너의 큰 배치와 중앙의 빈 공간을 참조해 유지한다.
- 파일: `public/assets/coin-tower/backgrounds/sky_ruins_noon.png`, `sky_ruins_evening.png`, `sky_ruins_night.png`. 원본 `sky_ruins.png`는 수정하지 않았다.
- 테스트용 구간과 부드러운 전환 규칙은 [시간대 배경](design/backgrounds.md)을 따른다. 현재 런타임에서 원본과 새 배경을 모두 사용한다. 실제 플레이 가독성과 전환 정렬은 [검증 기록](VALIDATION.md)의 관찰 한계를 따른다.
- 실제 출력 크기·세부 구도 차이·프롬프트·관찰 한계는 [제작 기록](art/background-time-of-day.md), 이용 조건은 [자산 출처](ASSET_SOURCES.md)를 따른다.

## Perfect 콤보 숫자

- [결정] 기존 `public/assets/coin-tower/perfect.png`를 유지하고 아래 줄에 X와 숫자 PNG를 조합해 `X1`, `X2`, …를 표시한다. 2026-10-08 사용자 요청을 따른다.
- 기준: 원본 Perfect의 둥글고 굵은 금색 글자, 밝은 윗면 하이라이트, 주황색 입체 측면, 짙은 적갈색 외곽선. 숫자는 기울이지 않고 같은 높이·기준선으로 정렬한다.
- 숫자마다 별·후광을 추가하지 않는다. 기존 Perfect 효과의 장식을 함께 사용한다.
- 파일: `public/assets/coin-tower/combo/x.png`, `0.png`~`9.png`. 투명 PNG, 공통 높이 192px, 글자 폭은 비례 유지. X는 대문자 모양이며 파일명만 소문자다.
- 게임 배치: Perfect 위 줄, 숫자 아래 줄. 자릿수가 늘면 가로 폭에 맞춰 축소하고 다음 이동 동전의 영역을 침범하지 않는다. 기존 피드백 시간에 함께 사라지며 정지·카운트다운 중 숨긴다.
- 생성·분리 과정과 출처는 [제작 기록](art/combo-glyphs.md), [자산 출처](ASSET_SOURCES.md)를 따른다. 사람의 가독성 평가는 자동 화면 검사와 구분한다.
