# 착지 손맛과 Perfect 연출

[게임 디자인](../GAME_DESIGN.md)으로 돌아가기.

## 목적과 플레이 경험

- [결정] 연출 개선의 첫 방향은 **착지 손맛 + Perfect 차별화**다. 매 성공에서 짧은 반동·접점 반짝임·구분되는 소리를 느끼도록 한다. 2026-10-11 사용자가 A안을 선택했다.
- [가설] 착지 순간의 시각·청각 반응을 맞추면 동전이 쌓이는 감각과 Perfect 성공감이 더 또렷해진다. 기존 연출과 비교한 사람 플레이로 확인한다.
- 이번 개선은 기존 NICE/PERFECT 페이드와 금색 이미지 숫자를 바탕으로 한다. 실제 체감·음색 평가는 아래 관측 조건을 따른다.

## 성공 순간의 반응

- [결정] 첫 동전을 포함한 일반 성공마다 새로 착지한 동전에 짧은 시각적 반동을 주고 접점에 작은 반짝임을 표시한다. 착지에 맞춰 일반 성공음을 한 번 재생한다.
- [결정] Perfect는 일반 성공과 구분되는 더 선명한 접점 반짝임과 소리로 강조한다. 기존 PERFECT/X 두 줄 배치를 기준으로 한다.
- [결정] 첫 Perfect부터 위 줄에 기존 PERFECT!, 아래 줄에 이미지 글자로 X1·X2·X3…를 표시한다. 숫자는 Perfect 피드백과 함께 사라진다.
- [결정] 실제 착지 좌표·가로 중심·판정·점수·다음 동전의 목표는 기존 규칙을 따른다. 시각적 반동은 착지한 동전의 짧은 반응이며 탑 물리 시뮬레이션이 아니다.
- [결정] 연출은 다음 동전이나 착지 목표를 가리거나 추가 대기 시간을 만들지 않는다. 착지와 다음 동전 사이의 기존 정착 시간 안에서 반동을 마친다.
- [결정] 성공음은 일반 착지보다 Perfect가 밝고 높게 들리는 방향으로 구분한다. 현재는 기존 짧은 임시 착지 음원의 재생 속도·높이 차이를 사용한다. 최종 금속 접촉음의 질감은 비교 청취 후 조정할 수 있다.

## 강도와 시작값

- [결정] 추천한 B 강도의 또렷한 반응으로 구현한다. 2026-10-11 사용자의 “좋아 연출부분도 구현진행해줘” 요청을 따른다.
- [결정] 일반 성공: 새 동전이 살짝 눌렸다 복원되고 접점 양옆에 소량의 금빛 입자가 짧게 퍼진다. NICE는 현재 표시 영역을 유지한다.
- [결정] Perfect: 일반 성공보다 선명한 접점 반짝임과 별 모양 입자, PERFECT/X의 짧은 확대·복원을 함께 사용한다. 확대는 두 줄이 서로 겹치지 않는 방향으로 진행한다.
- 현재 시각 구분 조정: NICE는 작은 따뜻한 금색 원형 입자와 짧은 접점 빛, Perfect는 큰 흰빛·금색 네 갈래 별과 두 겹의 퍼지는 접점 링을 사용한다. 링은 Perfect에서만 표시하고 동전 중심을 빛으로 채우지 않는다.
- [가설] 크기 차이뿐 아니라 입자 형태·색·링의 유무를 달리하면 무음에서도 착지 등급을 더 쉽게 구분할 수 있다. 최초 연출은 사용자가 이미지상 비슷하게 느꼈으므로 기존 시각 구분이 충분하다는 가설은 지지되지 않았다. 조정 후 재확인이 필요하다.
- [결정] 사용자의 후속 피드백에 따라 반동은 현재 강도를 유지한다.
- [가설] 현재 조정 기준은 일반 반동 140ms·최대 눌림 6%, Perfect 반동 180ms·최대 눌림 8%, Perfect 문구 팝 180ms·최대 확대 8%다. 입자는 일반 160ms·4개, Perfect 260ms·8개다. 피드백 전체 표시 시간은 기존 기준을 유지하고 반동·팝 종료 뒤 기존 크기로 돌아온다. 이 수치는 체감으로 조정할 시작값이며 최종 확정값이 아니다.
- [가설] 일반 성공음은 기존 음원의 재생 속도 0.88·효과음 상대 음량 0.9, Perfect는 1.24·1로 시작한다. 사용자·플랫폼 음량 설정을 함께 적용한다.
- 런타임 연출 조정값은 `src/game/feedback.ts`에서 관리한다. 게임의 착지 판정·정착 시간은 [게임 디자인](../GAME_DESIGN.md)의 소유다.
- [결정] 콤보 숫자는 무제한으로 표시하되 연출의 크기·밝기·소리는 유한한 강도로 유지한다. 자릿수에 맞춘 기존 폭 제한과 정렬을 보존한다. 콤보 구간마다 강해지는 별도 리듬 연출은 이번에 선택한 범위가 아니다.

## 중단·소리·접근성

- [결정] 착지 반동·입자·문구의 시간은 게임의 정지·재개 규칙을 따른다. 정지·카운트다운 중 성공 문구와 입자를 숨기며 효과음을 재생하지 않는다. 재개가 같은 착지음을 다시 울리지 않는다. 새 판·HOME에서 이전 효과를 초기화한다.
- [결정] 사용자 음소거와 CrazyGames 플랫폼 음소거를 적용한다. 플랫폼 음소거 중에도 성공을 시각적으로 구분할 수 있어야 한다.
- 동작 줄이기를 켜면 동전 반동·문구 확대·이동 입자를 생략하고 120ms의 고정 접점 반짝임과 NICE/PERFECT 구분을 유지한다. 기존 접근성 설정에 맞춘 구현 동작이다.

## 플레이에서 확인할 조건

1. 일반 착지 한 번에 반동·접점 반짝임·일반 성공음이 한 번씩 반응한다. 첫 동전도 반응하지만 Perfect/X1로 표시하지 않는다.
2. Perfect의 밝은 접점·소리와 문구 반응을 일반 성공과 구분할 수 있다. 무음에서도 구분된다.
3. 반동 후 동전은 실제 착지 위치·원래 모양으로 돌아오며 다음 동전의 목표나 성공 판정이 변하지 않는다.
4. 5·10·20개에서 다음 낙하를 결정할 때 이동 동전·목표가 보이고, 기존 정착 시간이 늘어나지 않는다. X10·X100도 영역 안에 들어온다.
5. 효과 중 정지·재개·재시작·HOME을 해도 효과나 소리가 중복되거나 새 판에 남지 않는다. 음소거와 동작 줄이기에서도 성공 의미를 유지한다.
6. 사람 비교 플레이에서 “쌓이는 반응이 또렷해졌다”는 느낌과 Perfect 구분, 다음 입력의 방해 여부를 각각 확인한다. 자동 검사 통과만으로 쾌감이 개선됐다고 확정하지 않는다.

## 영향을 받는 시스템

- [착지·Perfect·속도·중단](../GAME_DESIGN.md#착지적층실패): 착지 결과와 타이밍을 기준으로 반응하며 게임 규칙을 바꾸지 않는다.
- [기록](records.md): 콤보 집계와 완료 시 저장을 따른다. 기록 돌파 축하나 저장 시점 변경은 별도 주제다.
- [시간대 배경](backgrounds.md): 페이드와 함께 표시돼도 동전·목표의 가독성을 유지해야 한다.
- [아트 방향](../ART_DIRECTION.md): 기존 금화·금색 글자와 두 줄 구도를 따른다. 숫자 이미지 자체에는 장식을 덧붙이지 않는다.

## 구현 상태와 남은 결정

- 착지 반동·접점 입자·Perfect/X 팝·기존 음원의 일반/Perfect 재생 차이를 구현했다. 실제 관측 결과는 [검증 기록](../VALIDATION.md)과 [플레이 관측](../PLAYTEST_NOTES.md)에 구분한다.
- 성공감·소리 질감·강도의 적절성은 사용자 비교 플레이가 필요하다. 콤보 단계별 리듬과 기록 돌파 축하는 후속 주제다.
