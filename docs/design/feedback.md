# 착지 손맛과 Perfect·실패 연출

[게임 디자인](../GAME_DESIGN.md)으로 돌아가기.

## 목적과 플레이 경험

- [결정] 연출 개선의 첫 방향은 **착지 손맛 + Perfect 차별화**다. 매 성공에서 짧은 반동·접점 반짝임·구분되는 소리를 느끼도록 한다. 2026-10-11 사용자가 A안을 선택했다.
- [가설] 착지 순간의 시각·청각 반응을 맞추면 동전이 쌓이는 감각과 Perfect 성공감이 더 또렷해진다. 기존 연출과 비교한 사람 플레이로 확인한다.
- [결정] Perfect 강화는 **짧은 접점 폭발 + 동전 테두리 잔광**의 혼합형으로 진행한다. 스킨에 따라 연출 색을 구분한다. 2026-10-17 사용자가 C안을 선택했다. 기존 NICE/PERFECT 표시와 금색 이미지 숫자를 바탕으로 한다.
- [가설] 순간의 강한 반응 뒤에 짧은 스킨색 잔광을 남기면 Perfect의 성공감과 스킨의 개성이 함께 드러난다. 강화 전 Perfect가 밋밋하다는 사용자 피드백을 바탕으로 하며, 기존 별·링의 형태 차이만으로 성공감이 충분하다는 가설은 지지되지 않는다. 혼합형의 색·형태·시간·줌 연결은 로컬 개발/배포에서 관측했고 실제 성공감은 사람 비교 플레이로 확인한다.

## 성공 순간의 반응

- [결정] 첫 동전을 포함한 일반 성공마다 새로 착지한 동전에 짧은 시각적 반동을 주고 접점에 작은 반짝임을 표시한다. 착지에 맞춰 일반 성공음을 한 번 재생한다.
- [결정] Perfect는 일반 성공과 구분되는 더 선명한 접점 반짝임과 소리로 강조한다. 기존 PERFECT/X 두 줄 배치를 기준으로 한다.
- [결정] 첫 Perfect부터 위 줄에 기존 PERFECT!, 아래 줄에 이미지 글자로 X1·X2·X3…를 표시한다. 숫자는 Perfect 피드백과 함께 사라진다.
- [결정] 실제 착지 좌표·가로 중심·판정·점수·다음 동전의 목표는 기존 규칙을 따른다. 시각적 반동은 착지한 동전의 짧은 반응이며 탑 물리 시뮬레이션이 아니다.
- [결정] 연출은 다음 동전이나 착지 목표를 가리거나 추가 대기 시간을 만들지 않는다. 착지와 다음 동전 사이의 기존 정착 시간 안에서 반동을 마친다.
- [결정] 성공음은 일반 착지보다 Perfect가 밝고 높게 들리는 방향으로 구분한다. 현재는 기존 짧은 임시 착지 음원의 재생 속도·높이 차이를 사용한다. 최종 금속 접촉음의 질감은 비교 청취 후 조정할 수 있다.

## 강도와 시작값

- [결정] 일반 성공의 또렷한 반응을 유지하고 Perfect는 혼합형으로 강조한다. 착지 반동은 기존 강도를 기준으로 한다.
- [결정] 일반 성공: 새 동전이 살짝 눌렸다 복원되고 접점 양옆에 소량의 금빛 입자가 짧게 퍼진다. NICE는 현재 표시 영역을 유지한다.
- [결정] Perfect: 착지 접점 양끝에서 밝은 빛과 스킨색의 짧은 빛줄기가 튀어나오고, 착지한 동전 가장자리에 얇은 잔광과 소량의 별빛이 빠르게 사라진다. 기존 PERFECT/X의 짧은 확대·복원을 함께 사용하며 두 줄이 겹치지 않게 한다.
- [결정] Perfect의 접점 폭발·테두리 잔광·별빛은 해당 판에 사용 중인 동전 스킨의 색 계열로 맞춘다. 공통으로 밝은 중심 빛을 사용해 스킨색과 착지 순간을 함께 읽게 한다. 연출 형태와 강도 기준은 스킨 간 동일하게 두며 팔레트·재질 표현은 [아트 방향](../ART_DIRECTION.md#perfect-파티클과-스킨색)을 따른다.
- [결정] 빛은 접점과 착지 동전의 가장자리에 집중하고 동전 중심·착지 목표를 넓게 덮지 않는다. 다음 동전의 이동 시작까지 접점 폭발과 잔광을 정리하며 추가 대기 시간을 만들지 않는다.
- NICE의 작은 금색 원형 입자와 짧은 접점 빛은 현재 표현을 기준으로 한다. NICE까지 스킨색을 확장하는 것은 후속 제안이며 이번 C안의 필수 범위가 아니다.
- [결정] 사용자의 후속 피드백에 따라 반동은 현재 강도를 유지한다.
- [가설] 반동·문구 팝의 현재 조정 기준은 일반 반동 140ms·최대 눌림 6%, Perfect 반동 180ms·최대 눌림 8%, Perfect 문구 팝 180ms·최대 확대 8%다. NICE 입자는 160ms·4개를 기준으로 한다. 혼합형 Perfect의 접점 폭발·잔광은 합쳐서 약 250ms를 시작값으로 조정하며, 별의 수·빛줄기의 폭·밝기는 작은 화면과 연속 Perfect를 보며 맞춘다. 피드백 문구 전체 표시 시간은 기존 기준을 유지하고 반동·팝 종료 뒤 기존 크기로 돌아온다. 수치는 체감으로 조정할 시작값이며 최종 확정값이 아니다.
- [가설] 일반 성공음은 기존 음원의 재생 속도 0.88·효과음 상대 음량 0.9, Perfect는 1.24·1로 시작한다. 사용자·플랫폼 음량 설정을 함께 적용한다.
- 런타임 연출 조정값은 `src/game/feedback.ts`에서 관리한다. 게임의 착지 판정·정착 시간은 [게임 디자인](../GAME_DESIGN.md)의 소유다.
- [결정] 콤보 숫자는 무제한으로 표시하되 연출의 크기·밝기·소리는 유한한 강도로 유지한다. 자릿수에 맞춘 기존 폭 제한과 정렬을 보존한다. 콤보 구간마다 강해지는 별도 리듬 연출은 이번에 선택한 범위가 아니다.

## 실패 순간의 반응

- [결정] 실패한 동전만 착지 목표 중심에서 빗나간 방향으로 기울어 떨어진다. 기존 탑은 고정하고 짧은 실패 연출 뒤 결과 화면을 표시한다.
- [결정] 첫 실패 순간 판은 종료된다. 결과 화면을 기다리는 동안에도 추가 낙하·새 동전·점수 증가는 없다. 완료 기록의 확정·보존은 [기록 설계](records.md#기록-확정과-보존), 별조각 정산은 [경제 설계](economy.md#별조각-획득)를 따른다. 연출 종료를 기록·보상 확정 조건으로 추가하지 않는다.
- [결정] 결과 화면이 실패 동전의 초기 움직임을 가리지 않도록 연출 뒤에 표시한다. 카메라 구도는 [실패 규칙](../GAME_DESIGN.md#착지적층실패)을 따르고, 결과 화면 이후에는 기존 TRY AGAIN·MENU 흐름을 사용한다.
- [결정] 실패 판정에서 결과 표시까지의 초기 검증 시간은 약 0.4초로 한다. 동작 줄이기 설정에서는 회전·낙하 대신 고정된 MISS를 보여 준 뒤 결과 화면을 표시한다.
- [가설] 동전이 쌓이지 못하고 떨어지는 모습이 보이면 무음에서도 실패를 알아보고 이유를 납득하기 쉽다. 성공 범위를 넓힌 뒤에도 실패 동전이 지지돼 보인다는 [기존 관측](../PLAYTEST_NOTES.md#2026-10-11--일반-성공-범위-확대-후-브라우저-관측)을 바탕으로 한다. 왼쪽·오른쪽 경계 바로 밖과 크게 빗나간 실패를 사람 플레이로 비교한다.
- [가설] 이 시간 안에서 실패 방향을 읽고 빠르게 다시 도전할 수 있다. 회전·이동 강도와 결과 전환 시간은 구현 후 실패 이유의 가독성과 대기 체감을 함께 보며 조정한다.

실패 가설 관측 상태(2026-10-17): 좌우 방향별 실패 표시·즉시 정산·지연된 결과·동작 줄이기의 MISS는 런타임에서 확인했다. 실패 이유를 납득하는지와 대기 체감은 판단 유보다. [플레이 관측](../PLAYTEST_NOTES.md#2026-10-17--첫-품질-개선의-입력저장목표-흐름)을 따른다.

## 중단·소리·접근성

- [결정] 착지 반동·입자·문구의 시간은 게임의 정지·재개 규칙을 따른다. 정지·카운트다운 중 성공 문구와 입자를 숨기며 효과음을 재생하지 않는다. 재개가 같은 착지음을 다시 울리지 않는다. 새 판·HOME에서 이전 효과를 초기화한다.
- [결정] 사용자 음소거와 CrazyGames 플랫폼 음소거를 적용한다. 플랫폼 음소거 중에도 성공을 시각적으로 구분할 수 있어야 한다.
- 동작 줄이기를 켜면 동전 반동·문구 확대·이동 입자를 생략하고 120ms의 고정 접점 반짝임과 NICE/PERFECT 구분을 유지한다. 혼합형 Perfect도 이동·퍼짐 대신 해당 스킨색의 고정 접점 빛으로 대체한다.

## 배경음

- [결정] 사용자가 제공한 Suno 제작곡 `Arcade Sparkle`을 배경음으로 사용한다(2026-10-18).
- [결정] 배경음은 게임이 진행 중일 때만 반복 재생하며 실패 판정 순간에 끊는다. 실패 연출·결과·상점·메뉴에서는 재생하지 않는다(2026-10-19 사용자 요청). 게임 오버 효과음은 후속 작업이다.
- 메뉴의 시작·결과의 재도전에서는 곡을 처음부터 재생한다. 최초 로딩·메뉴에서는 음악을 시작하지 않으며, 진행 중 MENU로 돌아가도 음악을 끝낸다.
- 수동 정지·탭 숨김·포커스 이탈과 재개 카운트다운 동안 음악을 멈추고 실제 플레이 재개 시 같은 위치부터 잇는다. 사용자 음소거와 플랫폼 음소거는 기존 공통 소리 정책을 따른다.
- 초기 설정은 기존 master 0.7·music 0.35를 사용하고 저장된 설정을 보존한다. 착지 효과음과의 청취 균형·곡 끝과 처음의 음악적 연결감은 사용자 플레이에서 조정한다.

## 플레이에서 확인할 조건

1. 일반 착지 한 번에 반동·접점 반짝임·일반 성공음이 한 번씩 반응한다. 첫 동전도 반응하지만 Perfect/X1로 표시하지 않는다.
2. Perfect의 밝은 접점·소리와 문구 반응을 일반 성공과 구분할 수 있다. 무음에서도 구분된다.
3. 반동 후 동전은 실제 착지 위치·원래 모양으로 돌아오며 다음 동전의 목표나 성공 판정이 변하지 않는다.
4. 5·10·20개에서 다음 낙하를 결정할 때 이동 동전·목표가 보이고, 기존 정착 시간이 늘어나지 않는다. X10·X100도 영역 안에 들어온다.
5. 효과 중 정지·재개·재시작·HOME을 해도 효과나 소리가 중복되거나 새 판에 남지 않는다. 음소거와 동작 줄이기에서도 성공 의미를 유지한다.
6. 사람 비교 플레이에서 “쌓이는 반응이 또렷해졌다”는 느낌과 Perfect 구분, 다음 입력의 방해 여부를 각각 확인한다. 자동 검사 통과만으로 쾌감이 개선됐다고 확정하지 않는다.
7. 일반 동작 설정의 왼쪽·오른쪽 실패에서 실패한 동전만 빗나간 방향으로 기울어 떨어지고 기존 탑·점수는 유지된다. 결과 화면은 정한 초기 검증 시간의 연출 뒤에 나타나며 실패 동전은 적층 수에 포함되지 않는다. 동작 줄이기에서는 고정된 MISS로 실패를 구분한다.
8. 실패 연출 중 추가 입력이나 탭 전환이 완료 기록·별조각을 중복 확정하거나 완료 판을 중단 판으로 바꾸지 않는다. 결과에서 새 판을 시작하면 이전 실패 동전과 연출이 남지 않는다.
9. 사람 플레이에서 실패를 성공과 구별하는지, 실패 이유를 납득하는지, 재시작까지의 대기가 답답한지 각각 확인한다.
10. 금화·은화·루비·에메랄드의 Perfect에서 같은 흐름의 접점 폭발과 테두리 잔광을 보되 색 계열을 구별할 수 있다. 네 시간대 배경·전환 중·무음·동작 줄이기에서도 확인한다.
11. 20·60·100개와 작은 세로·가로 화면에서 연속 Perfect가 다음 이동 동전·착지 목표·PERFECT/X10·X100을 가리지 않는다. 줌이 진행 중이거나 하한에 도달해도 빛은 착지 동전을 따라가고, 문구의 크기는 유지된다.
12. 사람 비교 플레이에서 기존 연출보다 Perfect가 또렷하고 기분 좋게 느껴지는지, 스킨 색을 알아보는지, 반복 시 눈부심·주의 분산이 생기는지 각각 기록한다.

## 영향을 받는 시스템

- [착지·Perfect·속도·중단](../GAME_DESIGN.md#착지적층실패): 착지 결과와 타이밍을 기준으로 반응하며 게임 규칙을 바꾸지 않는다.
- [기록](records.md): 콤보 집계와 완료 시 저장을 따른다. 기록 돌파 축하나 저장 시점 변경은 별도 주제다.
- [경제](economy.md): 실패 연출보다 먼저 확정되는 완료 판의 정산을 따르며 결과 표시와 정산을 혼동하지 않는다. Perfect 연출 색은 해당 판의 스킨을 따르고, 상점에서 바꾼 스킨은 다음 판부터 사용한다.
- [시간대 배경](backgrounds.md): 페이드와 함께 표시돼도 동전·목표의 가독성을 유지해야 한다.
- [아트 방향](../ART_DIRECTION.md): 스킨별 연출 팔레트와 파티클 제작 방향을 따른다. 금색 글자·두 줄 구도를 유지하며 숫자 이미지 자체에는 장식을 덧붙이지 않는다.

## 구현 상태와 남은 결정

- 착지 반동·접점 입자·Perfect/X 팝·기존 음원의 일반/Perfect 재생 차이를 구현했다. 실제 관측 결과는 [검증 기록](../VALIDATION.md)과 [플레이 관측](../PLAYTEST_NOTES.md)에 구분한다.
- 혼합형 Perfect와 스킨별 연출 색을 구현했다. 기존 공통 금색 별·두 겹 접점 링을 짧은 접점 빛줄기와 동전 윤곽의 잔광·별빛으로 교체했다. 기존 반동의 표시 크기를 따라 잔광도 변형하고 모델의 카메라·줌을 함께 적용한다. 새 래스터 없이 Graphics로 표현하며 실제 관측과 남은 체감 평가는 검증 기록·플레이 관측에 구분한다.
- 기울어 떨어지는 실패 연출·고정 MISS 대체 표현·결과 전환 지연을 구현했다. 조정값은 `src/game/feedback.ts`의 `failureRules`에서 관리하며 세부 강도와 시간의 체감은 사람 플레이로 확인한다.
- 성공감·소리 질감·강도의 적절성은 사용자 비교 플레이가 필요하다. 콤보 단계별 리듬과 기록 돌파 축하는 후속 주제다.
