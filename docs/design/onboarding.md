# 첫 플레이 안내

[게임 설계로 돌아가기](../GAME_DESIGN.md)

## 목적과 플레이 경험

- [결정] 실제 플레이 안에서 가벼운 시각 힌트로 아래 동전에 맞춰 쌓는 목표와 낙하 조작을 안내한다.
- [가설] 목표 중심과 입력 제스처를 함께 보여 주면 별도 설명 없이 쌓기 규칙을 익히고 타이밍 도전에 들어갈 수 있다. 처음 보는 사람이 외부 설명 없이 낙하하고 착지 목표를 설명할 수 있는지 관찰한다.

## 안내 규칙

- [결정] 아래 동전이 있으면 작은 중심 눈금을 표시하고 클릭·탭 제스처로 낙하 입력을 안내한다. 첫 동전에는 입력 제스처를 표시한다. 조작은 [입력과 이동](../GAME_DESIGN.md#입력과-이동)을 따른다.
- [결정] 안내 중에도 실제 동전 이동·착지 판정·점수·보상을 그대로 사용한다. 동전을 목표 중앙에서 멈추거나 별도 연습 판을 두지 않으며, 안내 중에도 실패할 수 있다.
- [결정] 별도 설명창 대신 게임 안에서 안내하며 건너뛸 수 있게 한다. 안내를 건너뛰는 입력은 동전 낙하를 겸하지 않는다.
- [결정] 안내 완료 전에는 매판 성공 개수 0~4개의 좌우 이동 중에 안내를 표시한다. 한 판에서 다섯 번째 동전을 성공적으로 쌓거나 SKIP을 선택하면 안내를 완료하고 즉시 숨긴다. 그 전에 실패하면 다음 판에 다시 안내한다.
- [결정] 안내 완료 상태는 같은 브라우저·같은 사이트에 저장해 이후 판과 재방문에서는 안내를 숨긴다. 완료 전 일시정지·재개 카운트다운 중에는 안내를 숨기고 실제 플레이 재개 시 다시 표시한다.
- [결정] 안내 완료는 판의 기록·보상 확정과 별개다. 다섯 번째 성공이나 SKIP 이후 판을 중단해도 이미 완료한 안내는 다시 표시하지 않으며, 중단 판의 기록·보상은 기존 규칙을 따른다.
- [결정] 안내 완료 상태가 없는 신규·기존 사용자는 안내를 표시하는 상태로 시작한다. 기존 개인 기록·별조각·스킨 보유·장착은 보존한다.
- [결정] 저장할 수 없으면 완료 상태를 현재 페이지에서 유지해 다음 판에는 안내를 숨긴다. 새로고침 이후에는 마지막으로 정상 저장된 상태를 따른다. 저장 성공으로 안내하거나 기존 원본 데이터를 덮어쓰지 않는다.
- [결정] 넓은 가로 창에서는 플레이 기둥 왼쪽에 HOW TO PLAY 조작 안내(클릭/Space·P, 터치는 탭·Ⅱ 버튼)를 항상 표시한다. 기둥 안 첫 플레이 힌트 규칙은 그대로다.
- [결정] PC 일시정지는 `P`를 기본 키로, 기존 `Escape`를 보조로 받는다. Escape는 브라우저 전체화면 해제와 겹칠 수 있다.
- 힌트는 낙하 동전·착지 목표·Perfect 연출을 읽는 데 방해되지 않게 표시한다. [아트 방향](../ART_DIRECTION.md)의 작은 화면 가독성을 따른다.

## 플레이에서 확인할 조건

1. 안내를 읽기 위해 별도 화면이나 연습 판을 거치지 않고 실제 플레이를 시작할 수 있다.
2. 처음 보는 사람이 중심 눈금과 제스처를 보고 낙하 조작과 착지 목표를 이해한다. 자동 입력 성공을 학습의 근거로 삼지 않는다.
3. 건너뛰기는 안내만 닫고 동전을 떨어뜨리지 않는다. 안내 유무에 따라 이동 속도·판정·점수·보상이 달라지지 않는다.
4. 작은 PC·모바일 화면에서 눈금·제스처를 읽을 수 있고 동전·목표·Perfect를 가리지 않는다. 정지·카운트다운에서는 안내가 숨겨진다.
5. 5개를 쌓기 전 실패하면 다음 판에 안내가 다시 나타난다. 다섯 번째 성공이나 SKIP 뒤에는 새 판·메뉴 복귀·정상 저장 후 새로고침에서도 안내가 나타나지 않는다.
6. 안내 완료 뒤 진행 중인 판을 중단해도 완료 상태를 유지한다. 안내 상태 저장이 개인 최고·별조각·스킨 보유·장착 상태를 바꾸지 않는다.
7. 안내 완료 상태가 없는 기존 저장에서도 기존 진행을 보존하고 안내를 표시한다. 저장 실패 상태에서 5개 적층·SKIP 뒤 같은 페이지의 다음 판에는 안내가 숨겨지며 원본 저장 데이터가 유지된다.

## 영향을 받는 시스템

- [입력·착지·재시작](../GAME_DESIGN.md): 시작과 첫 낙하의 분리, 실제 착지 판정과 새 판 초기화를 따른다.
- [기록](records.md)·[경제](economy.md): 안내가 포함된 실제 판에도 일반적인 완료 기록·보상 규칙을 적용한다.
- 브라우저 저장: 안내 완료 상태의 보존은 기록·재화·스킨 데이터와 함께 호환성을 유지해야 한다. 기존 저장을 읽거나 이전하는 과정에서 원본을 잃지 않아야 한다.
- [착지·Perfect·실패 연출](feedback.md): 성공·실패를 가리는 안내를 피하고 실제 결과 피드백을 유지한다.
- [아트 방향](../ART_DIRECTION.md): 세로 화면 안에서 읽기 쉬운 안내와 필수 조작 배치를 조정할 때 함께 읽는다.

## 구현 상태와 남은 결정

- 가설 관측 상태(2026-10-17): 실제 입력·저장 이행·중단·재방문·저장 실패의 기계적 동작은 관측으로 지지된다. 처음 보는 사람의 조작 학습과 시각적 방해 여부는 판단 유보다. [플레이 관측](../PLAYTEST_NOTES.md#2026-10-17--첫-품질-개선의-입력저장목표-흐름)을 따른다.
- 중심 눈금·입력 제스처·SKIP과 v5 안내 완료 저장을 구현했다. 이동 중에 안내하고 낙하·정착 중에는 숨겨 입력 불가 단계와 구분한다. 신규·기존 저장·저장 실패의 관측과 한계는 [검증 기록](../VALIDATION.md)을 따른다.
- 눈금·제스처의 표시 강도·간격은 [아트 방향의 가독성 시작값](../ART_DIRECTION.md#화면-구성과-가독성)에 맞춰 구현 화면에서 조정한다. 안내 이해와 방해 여부는 사람 플레이로 확인한다.
- [미결] 후속 안내 다시보기 제공 여부. 이번 첫 개선 범위의 자동 안내·건너뛰기 동작은 구현했다.
