# 높이에 따른 시간대 배경

[게임 디자인](../GAME_DESIGN.md)으로 돌아가기.

## 목적과 범위

- [결정] 성공 적층 수가 10개 늘어날 때마다 배경 시간대를 바꾼다.
- [결정] 원본 아침 배경은 보존하고, 준비한 점심·노을 진 저녁·밤 변형을 사용한다.
- 구현 상태: 시간대 순환·크로스페이드·중단 상태 연동은 구현돼 있다. 새 전환 간격은 설계에 확정했으며 실행물에는 아직 적용하지 않았다. 실제 화면 관찰의 범위와 한계는 [검증 기록](../VALIDATION.md)을 따른다.
- 플레이 화면 밖 여백도 같은 시간대와 전환 상태를 따른다. 주변 확대·블러 표현의 기준과 조정 위치는 [아트 방향](../ART_DIRECTION.md#플레이-영역-바깥-배경)을 따른다.

## 전환 규칙

- [결정] 첫 구간은 아침, 성공 적층 수 10개에서 점심, 20개에서 저녁, 30개에서 밤으로 넘어간다. 실패한 동전은 구간 계산에 포함하지 않는다.
- [결정] 40개에서 아침으로 돌아가고, 이후에도 같은 순서로 10개마다 순환한다. 예를 들어 50개는 점심, 60개는 저녁, 70개는 밤이다.
- [결정] 즉시 교체하지 않고 이전 배경이 사라지면서 새 배경이 나타나는 부드러운 크로스페이드로 전환한다.
- [결정] 화면 전체를 검게 만드는 중간 구간 없이 두 배경을 겹쳐 바꾼다. 동전·Perfect·HUD는 배경과 함께 흐려지지 않고, 전환 중에도 기존 조작과 진행을 이어 간다.
- [가설] 전환 시간은 우선 1.2초를 조정용 시작값으로 사용한다. 시간대 차이를 알아볼 수 있으면서 다음 낙하 타이밍을 방해하지 않는지 관찰한다.
- [결정] 일시정지·탭 이탈·재개 카운트다운 동안 전환 진행도 멈추고, 플레이 재개 후 남은 전환을 이어 간다. 판 종료 시에는 보이던 배경 상태를 유지한다.
- [결정] 새 판과 메뉴는 아침 배경으로 되돌리고 이전 판의 전환 잔상을 남기지 않는다.

## 관찰할 결과

- 9→10, 19→20, 29→30, 39→40의 성공에서 해당 배경으로 한 번만 전환하며 경계 전에 바뀌지 않는다. 5·15·25·35개에서는 전환을 시작하지 않고 49→50 이후에도 순환한다.
- 전환 중 배경이 갑자기 튀거나 검은 화면이 나타나지 않는지 확인한다.
- 전환 중에도 금화·착지 목표·Perfect/X를 읽을 수 있는지, 재생 속도와 입력 타이밍에 방해가 없는지 관찰한다. 현재의 PC Perfect 표시 유지 피드백은 새 배경의 가독성을 검증하지 않는다.
- 저녁 이미지의 세로 1px 차이와 생성 이미지의 세부 윤곽 차이가 겹쳐 보이거나 흔들려 보이는지 확인한다.

## 관련 시스템과 자산

- [낙하·적층·속도](../GAME_DESIGN.md#착지적층실패): 성공 적층 수가 전환 기준이다. 배경 전환으로 점수·판정·속도는 바꾸지 않는다.
- [일시정지·재시작](../GAME_DESIGN.md#일시정지재개중단): 중단·재개와 새 판에서 전환 상태가 일관돼야 한다.
- [아트 방향](../ART_DIRECTION.md#시간대-배경), [제작 기록](../art/background-time-of-day.md): 원본과 세 변형의 파일·크기·생성 관찰 한계. 구간 값과 전환 동작은 이 문서에서만 관리한다.

## 조정과 남은 관찰

전환 기본 동작은 구현돼 있으며 이번 간격 변경은 후반 난이도 개선과 함께 적용한다. 구간·시간·순서의 런타임 편집 위치는 `src/game/backgrounds.ts`다. 전환 시간은 기존 시작값을 유지하며 실제 플레이에서 시간대 인식·Perfect 가독성·주의 분산을 관찰한다. 최종 전환 시간의 체감은 판단 유보다.

[가설] 배경 간격을 늘리면 각 시간대를 충분히 인식하고 낙하 타이밍에 집중하기 쉽다. 완만형 속도·줌과 함께 높은 구간에서도 전환이 너무 잦거나 드물게 느껴지는지 비교한다. [속도와 화면 추적](../GAME_DESIGN.md#속도와-화면-추적)의 가독성 검증과 함께 관찰한다.

브라우저의 구간·alpha·정지/재개·재시작과 캡처 관측은 [플레이 관측](../PLAYTEST_NOTES.md#2026-10-09--시간대-배경-전환-브라우저-관측)에 기록했다. 시간대 구분과 큰 배치 유지는 관측으로 지지되며, 1.2초 전환의 사람 체감은 판단 유보다.
