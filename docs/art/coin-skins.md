- 상태: 이미지 제작 완료·소비 기능 적용 전. 상점·구매·장착·저장 기능은 이번 작업에 추가하지 않았다.

## 장면 관측과 적용 경계

- PC 1280×900·Pixel 7 에뮬레이션의 Chromium에서 기존 금화 이미지 응답만 각 스킨 PNG로 임시 대체했다. 기존 Phaser `art` frame·표시 크기·게임 로직을 그대로 사용했다. 실제 구매·장착 경로를 검증한 것은 아니다.
- 금화와 세 스킨 각각에서 메뉴, 첫 NICE, 다음 Perfect/X1, 적층 5/10/15/20개의 점심/저녁/밤/아침 화면을 캡처했다. 마우스·터치와 개발 시간 제어를 사용했고 점수·좌표를 덮어쓰지 않았다. 마지막 입력은 중심을 벗어나 20개·최장 X19로 종료됐다.
- 기존 크기의 왕관·옆면·테두리가 보이고 보석 재질과 은색이 구분된다. 화면상 잘림·불투명 사각 배경·접점 밖 장식은 관측되지 않았다. NICE/Perfect의 기존 효과도 표시되며 페이지·자산 HTTP 오류는 0건이었다.
- 스크린샷·관측값: `test-results/coin-skins/`의 PNG와 `observations.json`. 실제 기기·사람의 선호/가독성·최저 사양 성능은 미확인이다. 테스트 스위트를 추가하거나 실행하지 않았다.
- CrazyGames 빌드에 파일은 복사되지만 자산 manifest·스킨 선택 기능에는 아직 연결하지 않았다. 기본 게임은 기존 금화를 사용하며, 세 스킨을 기본 로더에 추가해 동시에 메모리에 올리지 않는다.
