# CrazyGames 프리뷰 영상

최초 제작: 2026-10-14. **2026-10-20 재제작**: 사용자가 Basic 배포 준비로 가로·세로 영상을 요청했다. 기존 영상은 이전 5개 간격 배경, 측면 패널·이정표·배경 흐름 이전 화면, 개발 빌드의 자체 전체화면 아이콘이 담겨 있어 현재 CrazyGames 빌드로 다시 캡처했다.

## 제출 파일

| 파일 (`marketing/crazygames/videos/`) | 해상도          | 길이 | 용량            |
| ------------------------------------- | --------------- | ---- | --------------- |
| `coin-tower-landscape-1920x1080.mp4`  | 1920×1080, 16:9 | 18초 | 4,691,559 bytes |
| `coin-tower-portrait-1080x1620.mp4`   | 1080×1620, 2:3  | 18초 | 6,249,368 bytes |

공통: H.264 High, yuv420p, 25fps, MP4 faststart, 오디오 스트림 없음. `marketing/`에만 보관하므로 게임 다운로드에 포함되지 않는다.

2026-10-20 다시 확인한 [CrazyGames 공식 영상 요구사항](https://docs.crazygames.com/requirements/game-covers/#video-requirements)(15~20초, 50MB 이하, 16:9·2:3 1080p, 무음, 빨리감기 금지, 커버 첫 프레임, 검은 화면·검은 띠·기본 커서·홍보 문구·앱/소셜 아이콘 금지)을 따른다. 실제 포털 업로드·변환·심사는 아직 확인하지 않았다.

## 화면 구성 및 제작 방법 (2026-10-20)

- 처음 0.12초(3프레임): [기존 커버](crazygames-covers.md). 세로 커버는 800×1200에서 1080×1620으로 확대했다.
- 이후 17.88초(447프레임): 한 판의 연속 플레이 중 7개→26개 구간. 10개 `10 COINS!` 이정표와 아침→점심 전환, 배경 흐름, 20개 저녁 전환, 25개 이정표, Perfect 콤보와 가끔의 NICE를 보여 준다. 메뉴·결과 화면은 넣지 않았다.
- 가로는 1920×1080에서 측면 패널(COINS/BEST·HOW TO PLAY·일시정지/소리)을 포함한 실제 넓은 창 배치, 세로는 1080×1620에서 9:16 플레이 영역과 주변 흐림 배경이다. 검은 띠·외부 홍보 문구는 없다.
- 소스 `e565a8e`의 `vite --mode crazygames` 개발 빌드(자체 전체화면 아이콘 숨김)를 Playwright 1.63.0 / Chromium, DPR 1로 캡처했다. SDK는 local 환경의 최소 통제 객체로 대체했고 첫 플레이 안내 완료·기본 기록 상태로 시작했다.
- `scripts/record-preview-frames.mjs`가 `?debug`의 freeze/advance로 **게임 시간을 프레임마다 정확히 40ms(25fps)** 진행하며 PNG를 캡처한다. 점수·속도·판정·재화는 바꾸지 않고 읽기 전용 snapshot으로 위치를 보고 Space만 입력했다. 대부분 중앙, 일부는 20~26px 빗나가게 입력해 NICE도 섞었다. 정상 속도이며 빨리감기·건너뛰기는 없다. 사람이 직접 플레이한 기록은 아니다.
- 녹화 페이지에만 `cursor:none`과 포커스 외곽선 숨김 CSS를 넣었다. 게임 소스는 바꾸지 않았다.
- `scripts/encode-preview-video.py`로 커버 3프레임 + 캡처 196~642프레임을 FFmpeg 7.1(임시 Python 환경의 imageio-ffmpeg 0.6.0) libx264 `preset=slow`, `crf=18`, `-an`, `+faststart`로 인코딩했다. 프로젝트 의존성은 변경하지 않았다.

- 최종 MP4 전체 FFmpeg 디코딩 오류 없음. 18.00초, 25fps, 오디오 스트림 없음, 해상도·용량 확인.
- 영상에서 0초(커버), 3.3초(10개 이정표·Perfect X5), 12.5초, 17.6초(저녁·25개 이정표) 프레임을 추출해 가로·세로 모두 직접 확인했다.

공통: H.264 High / Level 4.2, yuv420p, 25fps, MP4 faststart, 오디오 스트림 없음. `marketing/`에만 보관하므로 게임 초기 다운로드에 추가되지 않는다.

### 화면 구성 및 출처

- 처음 0.12초(3프레임): [기존 커버](crazygames-covers.md). 세로 커버는 800×1200에서 확대했다.
- 이후 17.88초: 현재 게임의 연속 플레이. 금화 적층, Perfect 콤보, 5·10·15개 시간대 전환을 보여 준다. 금화 플레이에 집중하며 스킨 전환 컷은 넣지 않았다.
- 가로·세로 각각 해당 브라우저 크기로 따로 녹화했다. 실제 게임의 주변 흐림 배경을 포함하며 검정 여백·외부 홍보 문구·메뉴 화면을 삽입하지 않았다.
- 소스 체크포인트 `b3db7ae`. Playwright 1.63.0 / Chromium에서 로컬 Vite 개발 빌드를 녹화했다. 게임의 `?debug` 읽기 전용 snapshot으로 이동 위치를 관측하고 Space 키 이벤트를 자동 입력했다. freeze/advance나 점수·속도·재화·게임 규칙 변경은 사용하지 않았다. 사람이 수동 플레이한 기록이나 실기기 성능 측정은 아니다.
- 녹화 문서에만 `cursor:none`과 포커스 외곽선 숨김 CSS를 적용했다. 게임 소스는 변경하지 않았다. 개발 빌드라 자체 전체화면 아이콘이 보이며 CrazyGames 빌드는 해당 아이콘을 숨긴다.
- Playwright VP8 녹화에서 준비 구간을 잘라 정상 속도로 인코딩했다. FFmpeg 7.1 / libx264, `preset=medium`, `crf=18`, `-r 25`, `-an`, `-movflags +faststart`. 도구는 임시 Python 환경의 imageio-ffmpeg 0.6.0으로 준비했으며 프로젝트 의존성은 변경하지 않았다.
- 기존 게임 아트와 AI 생성 커버의 이용 조건을 따른다. 새 영상 생성 모델·외부 음원·제삼자 아트는 사용하지 않았다.

### 확인 결과

- 두 원본 녹화 모두 18개 / Perfect X17까지 진행, pageerror 없음.
- 최종 MP4 전체 FFmpeg 디코딩 오류 없음. 해상도, 18초, 25fps, 오디오 스트림 부재, 파일 크기 확인.
- 첫 프레임 커버, 가로 중간 Perfect, 세로 저녁 배경 및 녹화 마지막 밤 배경을 시각 확인했다.
- Chromium에서 각 파일을 처음부터 끝까지 재생한 결과는 [재생 기록](crazygames-preview-videos-playback.json), 파일 해시·인코딩 정보는 [메타데이터](crazygames-preview-videos-metadata.json)를 참고한다.
- 런타임 코드 변경이 없어 게임 회귀 테스트·재빌드는 실행하지 않았다. 업로드 후 CrazyGames에서 실제 미리보기의 크롭·재생을 확인하는 단계가 남아 있다.
